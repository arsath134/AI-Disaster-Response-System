# AI-Disaster-Response-System
AI-powered disaster response platform built using AWS cloud services including EC2, S3, Lambda, DynamoDB, SNS, and AI integration.

# AI Disaster Response System


AWS Serverless AI disaster management platform.


Services Used:

- S3
- Lambda
- DynamoDB
- SNS
- IAM
- EC2
- AI Processing


Flow:

User submits report

↓

S3 stores data

↓

Lambda processes incident

↓

AI analyzes severity

↓

DynamoDB stores result

↓

SNS sends alerts
